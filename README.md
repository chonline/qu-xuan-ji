# 趣玄机 - AI算命娱乐微信小程序

## 项目介绍
基于 PRD_V2 的 AI 玄学娱乐小程序，后端 Spring Boot + 前端微信小程序。

## 技术栈
- 后端: Java 1.8 + Spring Boot + MyBatis-Plus + MySQL
- 前端: 微信小程序
- AI: DeepSeek (默认) / Kimi / 通义千问

## 快速启动
1. 克隆仓库
2. 配置 application.yml 中的数据库和 AI Key
3. 运行 QuXuanJiApplication
4. 微信开发者工具打开 qu-xuan-ji-weapp

## 模块
- 每日运势、塔罗占卜、AI大师聊天、支付、VIP 等

更多详情见 PRD_V2.md
